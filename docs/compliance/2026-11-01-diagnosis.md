# 몇번더 1.0.0 규정·정책 진단 (2026-11-01)

**진단만 했습니다.** 코드·설정·데이터·배포는 하나도 바꾸지 않았습니다.
이 문서는 법률 의견이 아니고, 20개 항목을 확인했다고 해서 법적으로 안전하다는 뜻도 아닙니다.

**근거 구분 표시**
- 〔코드〕 저장소 파일에서 직접 확인한 사실
- 〔화면〕 자동 화면 검사(Playwright·axe) 결과
- 〔업체〕 외부 업체가 스스로 밝힌 내용(직접 검증 불가)
- 〔답변 필요〕 운영자 답이 있어야 판단 가능
- 〔법률 검토〕 해석이 갈려 전문가 판단이 필요

## 6. 법률 검토가 필요한 목록

1. 기기에만 남는 기록에 대해 운영자가 개인정보 보호법상 「개인정보처리자」인지. 처리자가 아니라면 처리방침·동의 범위가 어떻게 달라지는지

5. 이용자가 자녀(14세 미만) 정보를 적는 경우 법정대리인 동의가 필요한지
6. 1.1.0 일회성 인앱 구매의 청약철회 제한 표시, 통신판매업 신고와 신원정보 표시 의무, 앱마켓 결제일 때 누가 책임지는지
