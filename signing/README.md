# 서명 키

`debug.keystore` — APK 디버그 빌드에 쓰는 고정 키다.

## 왜 저장소에 두는가

Gradle은 `~/.android/debug.keystore`가 없으면 새로 만든다. CI는 매번 빈 기계라
빌드마다 키가 달라졌고, 안드로이드는 서명이 다른 앱을 기존 앱 위에 설치하지
않는다. 새 APK를 깔려면 매번 앱을 지워야 했고, 그때 기록(localStorage)도 같이
날아갔다.

키를 고정하면 덮어쓰기로 설치되고 기록이 그대로 남는다.

## 비밀이 아니다

안드로이드 디버그 키의 관례값을 그대로 쓴다.

    저장소 비밀번호  android
    별칭            androiddebugkey
    키 비밀번호      android

이 값들은 안드로이드 SDK가 정한 고정 규약이라 감출 수 있는 종류가 아니다.
이 키로는 구글 플레이에 올리거나 이미 올라간 앱을 갱신할 수 없다.

## 정식 배포를 하게 되면

스토어에 올릴 때는 이 키를 쓰면 안 된다. 별도의 릴리스 키를 만들어
GitHub Actions 비밀값으로 넣고, `assembleRelease`에 물려야 한다.
그 키는 잃어버리면 앱을 영영 갱신할 수 없으므로 따로 백업해 둘 것.
