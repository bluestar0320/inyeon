# 서명 키

APK는 정식(release) 키로 서명한다. 키 파일은 **저장소에 두지 않는다.**

## 어디에 있나

- GitHub Actions 비밀값
  - `ANDROID_KEYSTORE_BASE64` — PKCS12 키 파일을 base64로 바꾼 것
  - `ANDROID_KEYSTORE_PASSWORD` — 저장소·키 공통 비밀번호
  - 별칭은 `inyeon` (`.github/workflows/apk.yml`)
- 원본은 만든 사람의 컴퓨터(문서/몇번더-서명키)와 그 밖의 백업 한 곳 이상.

## 왜 이렇게 하나

예전에는 디버그 키를 이 폴더에 두고 썼다. 공개 저장소라 누구나 그 키로 똑같이
서명된 APK를 만들 수 있었고, 그런 가짜 "업데이트"는 진짜 앱을 덮어쓰고 기록을
읽을 수 있었다. 디버그 빌드는 USB 디버깅으로 앱 데이터를 꺼낼 수도 있었다.
(그 키는 git 기록에는 남아 있지만 더는 어떤 빌드도 쓰지 않는다.)

## 지킬 것

- 키를 잃어버리면 이미 설치된 앱을 영영 갱신할 수 없다. 백업을 두 곳 이상에.
- 키를 바꾸면 안드로이드가 기존 앱 위에 설치하지 않는다. 사용자는 백업 → 삭제 →
  새로 설치 → 불러오기를 해야 한다. 바꾸지 않는다.
- 구글 플레이에 올릴 때는 Play 앱 서명에 이 키를 업로드 키로 등록한다.
